# 실행 영상 촬영 가이드 (약 4분)

## 준비 (5분)
1. Pleos Connect Emulator 실행 (Cold boot) → 바탕화면이 뜰 때까지 대기
2. `apk/우희준_LvN_release.apk` 를 에뮬레이터 화면에 끌어다 놓아 설치
3. Lv.N 실행 → 권한 **허용** → 차종 **아반떼 N · 8단 습식 DCT** → **시연용 프로필로 시작**
4. 차고 화면 위쪽 **음성 안내 켬** 상태 확인 (효과음·음성도 녹화되게)

## 녹화 도구
- **Windows**: `Win + Alt + R` (Xbox Game Bar) — 에뮬레이터 창만 녹화됨
- **Mac**: `Cmd + Shift + 5` → 선택 부분 녹화 → 에뮬레이터 창 지정 (오디오 포함하려면 옵션에서 마이크/시스템 오디오 확인)
- 또는 OBS Studio (창 캡처 + 데스크톱 오디오)

## (선택) 실차 신호 30초 추가 촬영
차고 → **주행 시작** → Virtual Console에서
1. 기어 **D**, 속도 **60km/h** → 오른쪽 패널이 "주행 중에는 숨겨집니다"로 바뀌는 장면
2. 속도 **0**, 기어 **P** → 결과 화면

> 자막: "정차 중에만 정보 표시 · 주행 중에는 화면을 가립니다"

## 주의

- 배속은 자동 데모가 x2로 진행합니다. 더 짧게 하려면 재생 중 **배속** 버튼으로 x4.

# Lv.N — 운전할수록 성장하는 내 N 캐릭터

> 운전할수록 내 N 캐릭터가 성장하는 현대 N 전용 차량 RPG 앱.
> 재미로 키우다 보면 더 안전하게 운전하게 된다.

Pleos Connect(Android Automotive OS)용 앱입니다. 대상은 **가솔린 N · N 라인** 차량이며, 전기차와 하이브리드는 지원하지 않습니다.

---

## 1. 실행 방법

| 항목 | 내용 |
|---|---|
| APK 위치 | [`apk/우희준_LvN_release.apk`](apk/우희준_LvN_release.apk) |
| 설치 | Pleos Connect Emulator 화면에 APK 파일을 끌어다 놓기, 또는 `adb install -r apk/우희준_LvN_release.apk` |
| 실행 | 앱 목록에서 **Lv.N** 실행 → 권한 요청이 뜨면 **허용** |
| 처음 화면 | 차종 선택 → **시연용 프로필로 시작 (Lv.19 아반떼 N 오너)** 권장 |

### 테스트 환경
- Pleos Connect Emulator 2.1.0 (Android 14, API 34), RAM 4GB, Cold boot
- minSdk 28 / targetSdk 34, 외부 라이브러리 없음
- 화면 규격: Pleos Connect Emulator 2.1.0 기본 화면(가로형 차량 디스플레이). 차고 화면은 1600×900 기준으로 그린 뒤 화면 크기에 맞춰 확대·축소됩니다.

### 필요한 설정
- 권한 `android.car.permission.CAR_SPEED` 허용 (첫 실행 때 요청)
- 그 외 설정 없음. 인터넷 연결 없이 동작합니다(모든 데이터는 차량 안에만 저장).

## 2. 시연 방법

### A. 영상용 자동 데모 (버튼 하나)
차고 화면 오른쪽 아래 **영상용 자동 데모** → 아래 순서가 약 3분 30초 동안 자동으로 진행됩니다.

1. 차고 (Lv.19 · 캐릭터 · 스탯 레이더 · 컨디션/내구도)
2. 시나리오 1 **평일 아침 출근** → 결과
3. 시나리오 2 **금요일 밤 드라이브** → 결과 (**Lv.20 달성 · 인제스피디움 N 오너 트랙데이 참가권**)
4. 시나리오 3 **서킷 트랙데이** → 결과 (제로백·최고 속도 기록)
5. 정비 · 내구도 → 오너 랭킹 → 레벨 보상

### B. 시나리오 재생 (직접 고르기)
**시나리오 재생** → 3개 중 하나 선택. 재생 중 `배속 x1/x2/x4`, `끝까지 빠르게`, `중지`를 쓸 수 있습니다.

| 시나리오 | 무엇을 보여 주나 |
|---|---|
| 평일 아침 출근 | 누적 5km마다 체력 +1 / 깜빡이 차선변경 → 매너 +1 / 완만한 커브는 차선변경으로 세지 않음 / 깜빡이 없는 차선변경은 감점 없음 / 급가속·급제동 없이 ETA보다 일찍 도착 → 스피드 +1 |
| 금요일 밤 드라이브 | SPORT 모드 패들 변속 → 테크닉 / 과회전 다운시프트는 점수 없음 / 처음 가는 산길·야간·비 → 담대함 / 100km 돌파 → 체력 / 2시간 연속 운전 → 졸음쉼터 안내 → 휴식 후 컨디션 회복 |
| 서킷 트랙데이 | 등록 서킷 안에서만 스피드가 크게 오름 / 제로백·최고 속도 = 내 차 기록 |

> 시나리오는 0.2초 간격의 차량 신호(속도·기어·단수·방향지시등·조향각·야간·비·처음 가는 길·서킷)를 미리 만들어 둔 것입니다. 실차 신호와 **같은 판정 엔진**에 들어갑니다. 오른쪽 패널은 심사용으로 판정을 보여 주는 화면이고, 실제 주행 화면에는 나오지 않습니다.

### C. 실차 신호로 주행 (주행 시작 버튼 · Virtual Console)
차고 화면 왼쪽 아래 **주행 시작** → Emulator의 Virtual Console에서 값을 바꾸면 그대로 들어옵니다.
- 기어: P → D (또는 수동 단수 1~8), 속도, 방향지시등, 조향각
- 정차 중에는 신호 패널이 보이고, **속도가 1km/h를 넘으면 패널이 숨겨지고** 레벨 링만 남습니다.
- 다시 P로 바꾸면(20초 이상, 20m 이상 주행 후) 결과 화면이 열립니다.

## 3. 주요 기능

### 주행 중에는 소리로만
실차 신호 모드에서는 포그라운드 서비스(상단 "Lv.N 주행 기록 중" 알림)가 앱을 유지하므로, 내비 화면으로 바꿔도 판정과 효과음이 이어집니다. (현재는 신호 수신과 판정을 화면 쪽 코드가 맡고 있으며, 서비스 안으로 옮기는 작업은 다음 단계입니다.)
주행 중 화면에는 레벨 링과 이번 주행 XP만 보입니다. 판정은 짧은 효과음으로, 레벨업·장거리 돌파·졸음쉼터 안내·서킷 신기록만 음성으로 알려 줍니다. 결과·캐릭터·보상은 정차했을 때 열립니다.

### 5가지 스탯 (원칙: 방법이 아니라 결과 · 감점 없음 · 스피드 외 하루 상한 없음)
일상 운전에서는 체력·매너가 가장 많이 오르고, 테크닉·담대함이 그다음, 스피드는 공도에서 거의 오르지 않도록 점수 단위를 정했습니다. 캐릭터는 스탯별 등급 기준표(자주 오르는 스탯일수록 같은 등급에 더 많은 점수 필요)로 정해 공정하게 비교합니다.
| 스탯 | 오르는 조건 (구현 기준값) |
|---|---|
| **체력** | 누적 주행거리 5km마다 +1 (주행이 끝나도 남은 거리는 다음 주행으로 이어짐) · 정비 완료 기록 +10 |
| **매너** | 깜빡이를 켠 차선변경 +1 (10분 안에 3번째부터는 잦은 차선변경으로 보고 점수 없음 · 깜빡이 없는 차선변경은 감점 없이 기록만) |
| **테크닉** | 수동/패들 모드 적정 회전수 변속 10회마다 +1 (업시프트: 변속 전 2,800rpm 이상 → 변속 후 1,500rpm 이상 / 다운시프트: 변속 후 2,000rpm~레드존 200rpm 아래 · 연타 방지 3초 · 10초 안 왕복 변속 제외) · 적정 회전수(1,500~4,000rpm) 10분 유지 +1 · D 모드는 급가속·급제동 없이 30분 주행 +1 |
| **담대함** | 처음 가는 길 2km마다 +1 · 야간 10분 +1 · 빗길 10분 +1 |
| **스피드** | 공도: 급가속·급제동 없이 ETA보다 1분 이상 일찍 도착 +1 (**하루 최대 3회, 유일한 횟수 제한**) / 서킷: 트랙데이 완주 +5, 내 차 최고 속도·제로백 신기록 각 +10 |

- 급가속 11km/h/s, 급감속 7.5km/h/s: 한국교통안전공단 DTG 위험운전행동 기준 (서킷 안에서는 적용하지 않음)
- 차선변경 판정: 40km/h 이상, 3°~15° 작은 각도의 S자 조향이 3~8초 안에 끝날 때. 15°를 넘는 조향(교차로 회전, 급커브)은 핸들이 풀릴 때까지 판정하지 않습니다.
- RPM: 차량에서 받을 수 없으면 `속도 × 기어비 × 종감속비 ÷ 타이어 둘레`로 추정합니다 (차종별 기어비 내장, 근사치).

### 레벨 · 캐릭터 · 보상
- 스탯마다 0~100 등급. **상위 두 스탯 조합**으로 캐릭터가 정해집니다: 그리드의 제왕 · 스트리트 패밀리 보스 · 새벽 고개의 전설 · 마에스트로 · 지도 밖의 개척자 · 철인 크루저
- 레벨업마다 디지털 배지, 5레벨마다 한정 계기판 테마, 10레벨마다 N 굿즈 할인권, **Lv.20·40 인제스피디움 N 오너 트랙데이 참가권·할인권**(내 차로 달려 스피드 획득), Lv.30 HMG 드라이빙 익스피리언스 센터 우선 예약권(보조)
- 전체 오너 레벨 랭킹 (선택 참여, 닉네임·레벨·캐릭터명만 공개 — 앱 안의 순위표는 예시 데이터)

### 판정의 한계
| 판정 | 객관성 | 한계 | 대응 |
|---|---|---|---|
| 급가속·급제동 | 높음 | 속도 신호 갱신 주기에 따라 정밀도가 달라짐 | DTG 공식 기준(1초 단위) 적용 |
| 왕복 변속 | 높음 (기어 데이터 제공 시) | 기어 데이터 제공 여부 확인 중, 추월용 정상 변속도 제외될 수 있음 | 감점 없이 점수만 주지 않음 |
| 잦은 차선변경 | 중간 | ADAS 사용 불가로 차선변경을 핸들 패턴으로 추론 | 가점만, 실제 조향 신호 범위로 기준값 보정 |
| 변속 타이밍 | 중간 | RPM 추정값(일반 자동변속기는 저속 오차 큼), 적정 회전수 기준은 Lv.N이 정한 규칙 | DCT 차종부터 적용, RPM 제공 시 실측값으로 교체, 가점만 |

변속 직후의 충격(울컥임)은 지금 받을 수 있는 데이터로 직접 잴 수 없어 판정하지 않습니다.

### 컨디션 · 내구도
- 컨디션: 연속 운전 시간 기준. 2시간이면 졸음쉼터 안내, 15분 이상 쉬면 회복
- 컨디션 20% 이하(약 2시간 연속 운전) 또는 내구도 0%이면 그동안 얻는 경험치가 절반 (감점은 아님, 쉬거나 정비하면 원래대로)
- 내구도: 엔진오일(10,000km) · 타이어 위치 교환(10,000km) · 정기 점검(15,000km). 블루핸즈 원탭 예약(시연 화면), 정비 완료 기록 시 체력 +10

## 4. 구조

```
app/src/main/java/com/lvn/app/
├─ MainActivity.java        화면 (차고 · 시나리오 · 주행 · 결과 · 정비 · 랭킹 · 보상 · 설정)
├─ Feedback.java            효과음 + 음성 안내 (Android 표준 TextToSpeech)
├─ engine/
│  ├─ DriveSample.java      한 시점의 차량 상태 (실차든 시나리오든 같은 형식)
│  ├─ DriveEvent.java       판정 결과
│  └─ JudgeEngine.java      판정 엔진 (변속·차선변경·급가속/급제동·야간/비/새 길·컨디션·서킷)
├─ model/
│  ├─ Stat.java             5개 스탯과 등급 곡선
│  ├─ CharacterClass.java   상위 두 스탯 → 캐릭터
│  ├─ CarProfile.java       차종별 기어비·종감속비·타이어 둘레 (RPM 추정)
│  └─ Profile.java          레벨·스탯·정비 이력 저장 (기기 안 SharedPreferences)
├─ source/
│  ├─ LiveCarSource.java    CarPropertyManager 차량 신호 (리플렉션 연결)
│  └─ Scenario.java         시나리오 재생기 (출근 · 금요일 밤 · 서킷)
└─ ui/                      그리기 위젯 (스탯 레이더 · 원형 게이지 · 막대)
```

### 사용한 차량 데이터
| 데이터 | 출처 | 상태 |
|---|---|---|
| 속도 `PERF_VEHICLE_SPEED` | Android Automotive 표준 차량 속성 | 사용 |
| 기어 선택 `GEAR_SELECTION` / 현재 단수 `CURRENT_GEAR` | 〃 | 사용 (수동 단수 = M 모드) |
| 방향지시등 `TURN_SIGNAL_STATE` | 〃 | 사용 |
| 조향각 `PERF_STEERING_ANGLE` | 〃 | 사용 |
| 야간 `NIGHT_MODE` | 〃 | 사용 |
| 엔진 RPM `ENGINE_RPM` | 〃 | 권한이 없으면 추정값 사용 |
| 와이퍼(비), 처음 가는 길(위치), ETA | Pleos Vehicle SDK · FusedLocation · NaviHelper | 정식 배포 후 연결 (지금은 시나리오로 시연) |

판정 엔진은 신호 출처와 분리되어 있어, Pleos SDK 정식 배포 후에는 `LiveCarSource`만 SDK 호출로 바꾸면 됩니다.

## 5. 직접 빌드하기

### Android Studio
이 폴더를 열고 `app` 을 Run 합니다 (AGP 8.5.2 · Gradle 8.7 · JDK 17).

### 스크립트 (제출한 APK를 만든 방법)
`tools/build_apk.sh` — Android Studio 없이 aapt2 · javac · D8 · apksig로 APK를 만듭니다.
```bash
TOOLS=<android.jar·bundletool.jar·aapt2·lmf 폴더> KEYSTORE=<서명키.p12> KEYPASS=<비밀번호> ./tools/build_apk.sh
```

## 6. 개인정보
- 주행 데이터는 차 안에서만 처리하고 저장합니다. 외부 서버로 보내지 않습니다.
- (향후) 처음 가는 길 판정은 정확한 좌표가 아니라 100m 격자로만 기록합니다.
- 랭킹은 선택 참여이며 닉네임과 레벨·캐릭터명만 공개합니다.
